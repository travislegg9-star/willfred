# Woofa's Games

TanStack Start rebuild of Sheep Wrestling + Stick BMX from the original Willfred pack.

- Theatrical sheep wrestling: super/power/rare finishers, career unlocks, friend codes
- Stick BMX: dirt park, combo tricks, on-screen control toggle in settings

```bash
cd app
npm install
npm run dev
```

Dev server: `0.0.0.0:8080`
